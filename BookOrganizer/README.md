# Book Organizer

## Cara Mengunnakan Folder
Save List terdapat di Folder 'data'.
Jika ada List sendiri, masukannya di 'data' folder lalu jalankan programnya dan load list dengan ketik 8 lalu nama list (contoh : book_list2.json)

## Cara Menjalankan
"python src/main.py" pada termianl book_organizer/
